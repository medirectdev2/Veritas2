API Endpoint Reference

Method Path Query Params Source DB Tables Queried Returns
GET / — app.py — Renders calendar2.html
GET /api/doctors — app.py BookingCalendar, BookingSlot, UserAccount, Branch JSON list of 11 doctors [{id, name}]
GET /api/all_doctors — app.py BookingCalendar, BookingSlot, UserAccount JSON all doctors (no ID filter)
GET /api/slots start, end, doctor_id[] app.py BookingCalendar, BookingSlot, UserAccount, Branch, CaseService JSON available slots with doctor, branch, start/end times
GET /api/available-months doctor_id[] app.py BookingCalendar, BookingSlot, UserAccount, Branch (HSA filter) JSON month abbreviation list ["Jan","Mar",…]
GET /api/available-years — app.py BookingSlot (IsBooked=1, current year+) JSON year list [2025, 2026]
GET /api/doctor-link doctor (name) app.py — (hardcoded dict) JSON {doctorLink: "https://medirect.com.au/…"}
GET /api/booking-url doctor (name) app.py — (hardcoded dict) JSON {bookingUrl: "https://bookings.medirect.com.au/…"}
GET /api/doctor-invoice — doctor_invoice.py CaseInvoice, Contact, Organisation, Case, CaseType, UserAccount, ContactCategory JSON monthly invoice summaries grouped by doctor / sector / org
GET /api/doctor-calendar — doctor_calendar.py BookingCalendar, BookingSlot, UserAccount, Branch, CaseService, Case JSON daily slot counts per doctor with status and location
GET /api/doctor-analysis year, quarter, month, doctor_id doctor_analysis.py CaseInvoice, Case, UserAccount, CasePaidInvoice JSON revenue analytics per doctor with GST, % of total
